Interactive Command Shell Simulator

Operating security VMs (such as Kali Linux) relies heavily on command-line mastery. Browse commands by category on the left, click one to load its details, and run it in the emulator to observe expected terminal output.

File & Directory Management
ls -la
List files detailing sizes and hidden elements.
pwd
Output current working directory path.
cat /etc/passwd
View local user account mappings.
mkdir -p /tmp/cyber_lab
Create a new workspace directory structure.
User & Access Management
whoami
Identify the current active shell user.
id
Display user and primary group IDs.
sudo useradd -m analyst
Create a new system user profile.
File Permissions
chmod +x backup.sh
Mark a script file as executable.
sudo chown root:root file.txt
Change file owner and group to root.
Process Management
ps aux | grep apache
Find Apache server processes.
sudo kill -9 1402
Force terminate a process using PID.
Network Administration
ip a
Inspect network interfaces and IP addresses.
ping -c 3 192.168.56.103
Check target network reachability.
ss -antp
List listening ports and connections.
Package Management
sudo apt update
Update list of available app packages.
sudo apt install nmap -y
Install network mapping utility.
