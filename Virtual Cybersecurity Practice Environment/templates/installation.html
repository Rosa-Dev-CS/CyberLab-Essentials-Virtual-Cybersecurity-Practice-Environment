Virtual Hypervisor Environment Setup

Building an isolated sandbox network requires careful configuration. Below is your step-by-step workbook for importing virtual nodes and establishing secure boundary routing. Check off each box as you complete the corresponding step. Your progress is saved in real-time.

A hypervisor allows you to run virtual guest operating systems on top of your host machine. We recommend VirtualBox (free, open-source) or VMware Workstation Player.

VirtualBox Setup:

  1. Download the installer for your OS from the official portal: virtualbox.org.
  2. Execute the installer and accept default settings (includes installing virtual network interfaces).
  3. Crucial: Download and install the VirtualBox Extension Pack (adds support for USB 2.0/3.0 controllers and virtual disc acceleration).
💡 Virtualization Notice

Ensure Intel VT-x or AMD-V is enabled in your system's motherboard UEFI/BIOS settings, otherwise virtual machines will fail to boot or run extremely slowly.

Kali Linux is the preeminent Linux distribution for offensive security simulations. Downloading the pre-built VirtualBox image (`.ova` format) saves configuration time.

Import Steps:

  1. Download the VirtualBox Pre-built Image from kali.org/get-kali.
  2. Unpack the downloaded zip file (`.7z` format) to your virtual storage drive.
  3. Double-click the extracted .vbox file or select "Import Appliance" in VirtualBox, locating the downloaded .ova.
  4. Verify configuration: Allocation of at least 2 vCPUs and 2048 MB RAM.
  5. Boot the machine. Default logins are: Username: kali | Password: kali.

Practicing defender tasks (log reviewing, security policies) requires a Windows target. You can acquire evaluation licenses directly from Microsoft.

Installation Steps:

  1. Download a free 90-day evaluation ISO for Windows 10/11 Enterprise from the Microsoft Evaluation Center.
  2. In VirtualBox, select "New". Choose Type: Microsoft Windows.
  3. Mount the downloaded ISO inside the virtual optical drive settings.
  4. Boot the VM and complete the standard installation. Name the default administrator account (e.g. labuser).

Metasploitable 2 is a Linux machine built deliberately with outdated, exploitable packages. It acts as a target for vulnerability scanners and analysis.

Import Steps:

  1. Download the Metasploitable 2 zip file from SourceForge or official security mirrors.
  2. Extract the contents (you will see a virtual disk file `.vmdk`).
  3. In VirtualBox, create a new VM. Choose Operating System: Linux / Ubuntu (64-bit). Assign 1024MB RAM.
  4. At the "Hard Disk" prompt, select "Use an existing virtual hard disk file" and link the extracted .vmdk disk.
  5. Boot the machine. Default logins are: Username: msfadmin | Password: msfadmin.
⚠️ Safety Rule

Metasploitable has no firewall rules or patches. Proceed to Step 5 immediately to ensure it remains restricted inside Host-Only networking.

We will configure the dual network interfaces: NAT (for downloading patches on attacker/host VMs) and Host-Only (which routes all VM scanning traffic safely).

A. Create the Host-Only Adapter in VirtualBox:

  1. Navigate to Tools (or File -> Tools) -> Network Manager (Host Network Manager).
  2. Click Create. It will establish a virtual adapter name (e.g. VirtualBox Host-Only Ethernet Adapter).
  3. Configure Adapter parameters: IP address: 192.168.56.1 | Subnet Mask: 255.255.255.0.
  4. Enable the DHCP Server tab. Server IP: 192.168.56.100 | Address bounds: 192.168.56.101 to 192.168.56.254.

B. Assign Adapters to VM Nodes:

Virtual Machine Adapter 1 Adapter 2
Kali Linux NAT (Internet package downloads) Host-Only (Auditing segment)
Windows Target NAT (Updates/Defender feeds) Host-Only (Isolated LAN)
Metasploitable Host-Only only (No internet) None (Disabled)

Running security labs often involves deploying configurations that modify OS registry flags or user directories. Setting clean snapshots lets you rollback changes instantly.

Snapshot Best Practices:

  1. Shut down the target virtual machine (e.g., Metasploitable).
  2. Click the menu symbol next to the VM name in VirtualBox list and select Snapshots (or press Ctrl+T).
  3. Click Take. Name it: Clean_Base_State. Provide a description (e.g., "Initial import, network set to Host-Only").
  4. After practicing exercises, if you corrupt any services, shut down the VM, return to the Snapshots tab, click Clean_Base_State, and select Restore.
