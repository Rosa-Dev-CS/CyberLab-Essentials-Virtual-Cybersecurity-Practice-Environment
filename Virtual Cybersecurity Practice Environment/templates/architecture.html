Understanding Hypervisor Virtual Networks

🌐 NAT Network (Network Address Translation)

In NAT mode, the hypervisor acts like a home router. The guest VMs receive IP addresses on a private subnet (typically 10.0.2.x) and can access the external internet through the host's internet connection. However, the host computer and other external systems cannot connect directly to the guest VM.

🔒 Host-Only Network

This creates a fully loopbacked software switch. The host computer and all guest VMs connected to the Host-Only network can communicate with one another (often inside 192.168.56.x). Crucially, no internet access is available, and no external machines can route traffic into this segment. This is the optimal network for hosting targets.

🌉 Bridged Networking

Bridged mode connects the guest VM directly to your host's physical network adapter. The VM requests a lease from your home/office physical router (getting an IP like 192.168.1.x). The VM behaves exactly like a separate physical device on your LAN. Avoid using bridged mode for vulnerable machines like Metasploitable!
