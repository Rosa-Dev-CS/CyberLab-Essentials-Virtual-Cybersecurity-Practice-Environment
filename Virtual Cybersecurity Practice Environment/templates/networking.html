IP Addressing and Subnet Divisions

IPv4 addresses consist of 32 bits, divided into four 8-bit octets (e.g., 192.168.1.1). An IP address contains two components: the network prefix (identifying the specific subnet) and the host ID (identifying the individual device).

CIDR Notation:

Classless Inter-Domain Routing (CIDR) uses a slash followed by a number (e.g., /24) to denote the number of bits allocated to the network prefix. A /24 subnet mask allocates 24 bits for the network, leaving 8 bits (256 values) for host addresses.

Private RFC 1918 Ranges:

  • 10.0.0.0 – 10.255.255.255 (Class A)
  • 172.16.0.0 – 172.31.255.255 (Class B)
  • 192.168.0.0 – 192.168.255.255 (Class C)

DHCP vs. Static Network Configuration

Devices require IP parameters to join a network. This can be handled dynamically or mapped manually.

DHCP Lease Handshake (DORA):

  1. Discover: Client broadcasts a request for an IP address.
  2. Offer: DHCP Server offers a lease on an IP address.
  3. Request: Client requests the offered IP address.
  4. Acknowledge: Server approves the lease and sends configuration details.

Static Linux Netplan Example:

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      addresses:
        - 192.168.56.101/24
      gateway4: 192.168.56.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]

Routing Tables & Domain Name Resolution

How packets move across networks and how systems locate servers.

Packet Routing:

A host uses its local **routing table** to determine where to send packets. If the destination IP is on the local subnet, the host sends it directly. If the destination is external, the packet is forwarded to the **default gateway** (your router) to be routed across networks.

DNS Resolution Flow:

The Domain Name System (DNS) translates human-readable domain names (e.g., example.com) into computer-routable IP addresses. Clients query a DNS resolver, which checks its local cache before querying root servers, TLD servers, and authoritative name servers to resolve the domain.
