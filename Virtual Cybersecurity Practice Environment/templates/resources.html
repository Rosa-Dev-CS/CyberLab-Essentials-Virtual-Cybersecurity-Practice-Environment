Common Ports & Services

Port Protocol Description
21 FTP File Transfer (often cleartext)
22 SSH Secure Shell (encrypted CLI)
23 Telnet Cleartext Terminal Link
80 HTTP Web Server traffic (unencrypted)
443 HTTPS Encrypted Web Server traffic
445 SMB Windows File Sharing (Samba)
3306 MySQL Database Server socket

Utility Quick Syntax

Nmap (Scan top ports + OS + Scripts): nmap -sS -A -T4 192.168.56.103
Gobuster (Directory enumeration): gobuster dir -u http://192.168.56.103/ -w /usr/share/wordlists/dirb/common.txt
Netcat (Open a reverse shell listener): nc -lvnp 4444
Nikto (Standard web server check): nikto -h 192.168.56.103
Hypervisor
Software (e.g., VirtualBox, VMware) that creates and runs Virtual Machines, allocating physical CPU and RAM resources.
Host-Only Adapter
A virtual network interface that isolates VMs on a private network communicating only with the host and other VMs. No internet routing.
NAT (Network Address Translation)
Translates guest VM packets to the host's physical IP address, giving guest VMs internet access while hiding them from external ingress scans.
Bridged Adapter
Binds the VM directly to the host's physical network, making the VM appear as a separate node on your home/office LAN router.
Vulnerability
A flaw or loophole in software configurations that could be validated to trigger unauthorized actions.
Port Scanning
Sending packets to target socket addresses to verify if ports are open, closed, or filtered.
Packet Capture (PCAP)
Intercepting and logging raw data frames passing through network cards for analysis using utilities like Wireshark.
Sandbox Isolation
Running unpatched systems inside a sealed software environment (such as host-only VLANs) to prevent exposure.
Snapshot
A saved state of a virtual machine's storage and RAM, letting you rollback configuration errors instantly.
Cleartext Protocols
Network protocols (like HTTP, FTP, Telnet) that transmit payloads unencrypted, allowing anyone capturing packets to read authentication details.
DVWA
Damn Vulnerable Web Application - an PHP/MySQL target application designed to practice defensive security auditing.
